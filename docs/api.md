# API

Base local: `http://localhost:8000`.

Endpoints planificados:

- `GET /health`
- `GET /api/alerts`
- `GET /api/summary`
- `GET/POST/DELETE /api/data/{dataset}`
- `POST /api/data/{dataset}/upload`
- `POST /api/data/reset`
- `GET /api/orders-by-provider`
- `GET /api/export/pedido-corregido`
- `GET /api/anomalies`
- `GET /api/health-scores`
- `POST /api/chat`
- `POST /api/summary-ai`
